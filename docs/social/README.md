# Social and outreach assets

Standalone HTML cards rendered to images for social posts and talks, plus the
explainer graphic. They are self-contained pages — open one in a browser and
screenshot it; nothing here is built, imported or served by the app.

| File | What it is |
|---|---|
| `opencheck-social-b.html` | **The card in use.** Carries the live source count, so it is on the "add a new source" checklist in `CLAUDE.md` — the count here has to move with `README.md` and `docs/sources.md` |
| `opencheck-social-opt-a.html` | Option A (flag strip) — an earlier direction, kept for reference |
| `opencheck-social-opt-b.html` | Option B (diagram + flag panel) |
| `opencheck-social-opt-c.html` | Option C (bold geography) |
| `opencheck-explainer.jpg` | The explainer graphic |

They lived in the repository root until Phase 168, where the only thing
distinguishing the one that matters from the three drafts was that you had to
know.
