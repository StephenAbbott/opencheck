# Overview

Public contracts Greek contracting authorities post to ΚΗΜΔΗΣ, the Central Electronic Registry of Public Contracts, read live from its Open Data API (from 2017). For a supplier: its latest and largest contracts with authority, value, period, procedure and a link to each contract document, plus totals. Matched on the tax number (ΑΦΜ) the company's ΓΕΜΗ record publishes. Contracts won, not ownership. Aggregator, cross-border database or ESG source.

- **Category:** cdd (customer due diligence / compliance)
- **Search kinds:** entity
- **Requires API key:** no
