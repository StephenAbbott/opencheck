# Overview

Zambia Revenue Authority tax receipts, the EITI reconciliation payment report, employment, mining rights and WARMA water-permit offences from the Zambia EITI portal, for Zambian LEI holders matched to the portal by name (12 of 69 Zambian LEIs). Rows are keyed on the ZRA TPIN; GLEIF files the PACRA number, so the link is a name match made offline. Aggregator, cross-border database or ESG source.
