# Overview

New York entity records from the Department of State's Division of Corporations, looked up by DOS ID: every filing, the status after each one, every name the entity has held, and the chief executive officer a corporation names on its biennial statement. Official national company / beneficial-ownership register.

- **Source id:** `ny_dos`
- **Category:** cdd (customer due diligence / compliance)
- **Search kinds:** entity
- **Requires API key:** no
- **National register:** yes
- **Lookup keys (LEI-anchored dispatch):** `us_ny_dos_id`
