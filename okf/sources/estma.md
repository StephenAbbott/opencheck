# Overview

Payments to governments in Canada and abroad — taxes, royalties, fees, production entitlements, bonuses, dividends and infrastructure payments — reported each year by extractive companies under Canada's Extractive Sector Transparency Measures Act, from Statistics Canada's weekly republication of every report. The file is keyed by the ESTMA ID and carries no LEI; OpenCheck links 704 ESTMA entities to LEIs through a hand-reviewed name crosswalk. Aggregator, cross-border database or ESG source.

- **Source id:** `estma`
- **Category:** esg (environmental, social & governance)
- **Search kinds:** entity
- **Requires API key:** no
- **National register:** no
