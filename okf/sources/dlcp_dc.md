# Overview

Washington DC company registrations from DLCP's Corporations Division, looked up by file number: name, status, entity type, address, registered agent, trade names, and the owners and controllers filed on the biennial report under D.C. Code § 29-102.11(a)(6). Official national company / beneficial-ownership register.

- **Source id:** `dlcp_dc`
- **Category:** cdd (customer due diligence / compliance)
- **Search kinds:** entity
- **Requires API key:** no
- **National register:** yes
- **Lookup keys (LEI-anchored dispatch):** `us_dc_file_number`
