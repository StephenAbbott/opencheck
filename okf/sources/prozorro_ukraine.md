# Overview

Public contracts Ukraine publishes on Prozorro, read daily from Prozorro's API by OpenCheck. For a supplier: its latest and largest contracts with buyer, value, procedure and a link to each contract on Prozorro, plus totals over the active and terminated contracts changed since the harvest began, a period the card states. Contracts with natural persons are not read. Matched on the EDRPOU. Contracts signed, not ownership. Aggregator, cross-border database or ESG source.
