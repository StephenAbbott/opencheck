Prozorro's central database (`public.api.openprocurement.org/api/2.5`, CC BY 4.0, keyless) has no supplier filter: `/contracts` and `/tenders` are change feeds of id and `dateModified`, unknown parameters are ignored, and the supplier is only on the full contract. So `opencheck/prozorro_harvest.py` reads the contracts feed forward from a saved cursor and fetches every changed contract (sixteen at a time, ~15 a second, no 429 measured), reads each tender's procedure from the tenders feed's own `opt_fields`, and keeps one row per contract in a SQLite store carried between runs on the `prozorro-harvest` release; `sources/prozorro_ukraine.py` builds the supplier index from it (`prozorro-index`, downloaded at boot, the MTender shape: `fetch_by_identifiers` / `applies_to`, not announced without the index, no identifier asserted on the hit, one `UA-EDR` entity statement). Stephen's four decisions (23 Nov 2026, on the Notion ticket): (A) backfill twelve months, then daily; (B) a ten-digit РНОКПП supplier — a natural person, 46% of supplier rows in a 3,000-contract sample, sole traders included — is dropped by the harvester and nothing about it is stored; (C) active and terminated contracts are counted, terminated ones labelled, pending and cancelled left out; (D) a daily GitHub workflow, run once by hand first, with a hand-run harvest and release asset as the fallback if Prozorro refuses the runners. Found while building: buyers file a withheld defence supplier under martial law as "Оборонний постачальник" with code 88888888 (5% of the first kept contracts) — not a company, never stored; most reported purchases file no contract title, so the first item's description stands in; the oldest EDRPOUs lose their leading zeros, so five to seven digits are padded. The card lists the latest six and largest three contracts with links to prozorro.gov.ua/contract/<contractID> and says the harvest covers contracts changed since it began, not every contract ever. After merge, dispatch `refresh-prozorro-index` by hand until the log says caught_up (about sixteen runs for the year's backfill). The sanity check refuses an index under 5,000 suppliers; the first run's reading (~240,000 contracts) should clear it.
