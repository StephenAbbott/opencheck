Found in the Bulgaria MCP check of 19 Nov 2026: the register lookup of АКВАХИМ raised RELATED_PEP for Борислав Любенов Великов, while `/person-check` and `opencheck_person_check` on the same name raised nothing. OpenSanctions captions the record "Borislav Velikov" (0.78 against the full name) and files "БОРИСЛАВ ЛЮБЕНОВ ВЕЛИКОВ" as an alias; the person check scored the caption alone, the related-party screen every name. `_score_hit` now reads the record's names through `names.best_ftm_name`, as `cross_check` does since the Rosneftegaz ticket (caption, name, alias, previousName; never weakAlias), plus the label or alias a Wikidata search matched. A strong match then passes the related-party screen's hard filters, which the person check did not apply before: birth year, patronymic and the different-given-name refusal of PR #657, so Елица Петрова Рускова, now 0.905 against НЕЛИ РУСКОВА ПЕТРОВА, still gets nothing. Each match and each signal's `evidence.match` carry `matched_name`; a match without a shared birth year or nationality still reads "Possible name match only". After deploy: Великов gets a PEP signal from `/person-check`, Рускова none, and Equinor's and Ørsted's person checks are unchanged.
