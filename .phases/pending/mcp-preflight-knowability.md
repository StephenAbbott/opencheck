Two tickets from the 4 Nov 2026 review of NVIDIA's Auto Ontology MCP server, ahead of Connected Data London. **`opencheck_knowability(jurisdictions)`** wraps the knowability table (`statements_for` + `known_codes`, the same read as `GET /knowability`): one dated statement per ISO 3166-1 alpha-2 code — the sentence, `access` and its dates, the register, the row's sources and `opencheck_reads` with `reads_beneficial_owners` per source — shaped by `shaping.shape_knowability` to the public subset the results page shows, never the working-tracker fields. An unknown code is `stated_absence: true`, never an error. No source is called and no pipeline runs, so it is absent from `TOOL_TIERS` (default unit only) and charges no lookup budget: an agent asked "who owns this Cypriot company?" learns before any lookup that Cyprus publishes officers but no beneficial owners, which matters when a conference room behind one NAT address shares the budget. Tested through `mcp.call_tool` (the Phase 341 lesson), listed by the `/.well-known/mcp.json` descriptor and the data dictionary. **The handshake `_INSTRUCTIONS`** are rewritten as a short ordered guide — find, set expectations cheaply, check, read it honestly (`degraded_sources` means incomplete, `kind: context` is never a finding, a name match is not an identity, integrated figures are never added across sources, pass on `license_notices`), keep or hand on, many companies (batch, then the published bulk datasets rather than a loop of live lookups) — closing with which tools spend the lookup budget and that a 429's `retry_after_s` means wait, not retry at once. Four tools had been left unnamed (`person_check`, `person_positions`, `discrepancy_note`, `list_sources`); a test now pins that every `TOOL_NAMES` entry appears in the text and that it stays under `_INSTRUCTIONS_MAX_WORDS` (450). Check in production: `opencheck_knowability` for GB, CY, AZ (stated absence) and an unknown code, and a cold prompt in Claude Desktop ("who owns Danske Bank?") searches before it looks up and reports degraded sources as incomplete.
