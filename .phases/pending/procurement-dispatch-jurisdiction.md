---
title: ChileCompra and TED are announced only for companies they can answer about.
readme: ChileCompra is no longer listed as a source consulted for non-Chilean companies, nor TED for companies outside Europe.
tests: backend +12
---
Raised from production: looking up Eesti Energia and Danske Bank listed ChileCompra among the sources being checked. Both procurement sources kept their applicability test inside `fetch_by_identifiers`, which runs after `_dispatch` has scheduled the source and the stream has emitted `sources_applicable` and `source_started` for it — so the source was announced, counted in "N of N sources answered", and then quietly returned nothing. ChileCompra's only pre-dispatch gate was `covers_lei`, which asks whether the index file exists, not whether the company is Chilean, so every LEI with a `registeredAs` announced it. TED had the same shape: its EU/EEA/GB/CH jurisdiction check and its live-mode check both ran inside the fetch, so an American, Chilean or Japanese company announced TED too. The fix is the rule Phase 132 set for the offline indexes — applicability is decided before dispatch — applied to the two identifier-keyed procurement sources. Each adapter gains an `applies_to` predicate (ChileCompra: a Chilean RA and a RUT that passes the check digit and is outside the natural-person range; TED: live mode on, a jurisdiction inside TED's coverage or none recorded, and at least one identifier), `_dispatch` asks it before scheduling, and `fetch_by_identifiers` asks the same predicate again so the two cannot drift. Behaviour for companies the sources do apply to is unchanged, including TED still trying an anchor with no recorded jurisdiction. The existing TED dispatch test now turns live mode on, since a non-live TED is no longer announced. To check in production: Eesti Energia (5493005044RTLQ5RZU70) and Danske Bank (MAES062Z21O4RZ2U7M96) list neither ChileCompra nor, for a non-European anchor such as Apple, TED; a Chilean supplier still shows its ChileCompra card and Danske Bank still shows TED.
