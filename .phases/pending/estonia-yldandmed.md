RIK's general-data file (`yldandmed`, 1.5 GB unzipped, current rows only — no history, as measured on 16 Oct 2026) is the index's seventh file, read into a `general` table: columns for what most companies carry (capital, the `esitab_kasusaajad` filing obligation, the absence-report flag, main EMTAK/NACE activity, the latest annual report's year end and employees) and one JSON object for the rare lists (succession, status changes, activity periods, a branch's parent, predecessor references, shares without nominal value) — +42 MB SQLite, +7.6 MB gzipped on the real file. Contact details, real estate and contact persons' addresses are not carried, and a number shaped like a personal code is removed from every kept text unless the register calls it a registry code (a bankruptcy ruling names a sole trader by code; a Latvian company is eleven digits too). Stephen's decisions (16 Oct 2026): a company obliged to file beneficial owners with none on file is said in the finding ("beneficial owners due, none filed"; an exempt one, "beneficial owners not required") and counted at build time, not raised as a signal; a merger or division partner the index holds is an entity statement keyed on its registry code carrying the register's sentence, never a relationship (codes read after "registrikood" for 76% of divisions and 97% of mergers, any other eight-digit number only when the index holds it); every part of the ticket is in. Capital, main activity, the latest annual report, suspensions and predecessor references are `commenting` annotations on the company's statement. A foreign company's Estonian branch draws its parent with the parent's jurisdiction and a derived register identifier where the number has the shape (AAS BTA Baltic Insurance Company, Latvia), related by `otherInfluenceOrControl` and said to be part of it. The finding says an activity suspension in force, and an AS whose share register is kept by Nasdaq CSD with no shareholder in the open data now reads "shareholders kept at Nasdaq CSD" instead of "no shareholders on file" (`evks_registreeritud` is empty on every row, so the registrar on the card is read). The History tab gains the dated status changes (dissolution decisions, bankruptcies declared and ended, continuations) and every merger, division and transformation, naming the other companies. Two ticket assumptions did not hold: `KUST` marks re-registrations, not dissolutions, so no dissolution date is read; and the CSD flag is never filled. Builds on the card-entry branch (#444). After the next index rebuild: Eesti Energia shows 846,645,750.00 EUR capital, two divisions (2020 Tootsi Windpark, 2023 Liivi Offshore) on History with both companies drawn, "shareholders kept at Nasdaq CSD"-style wording where it applies, and 11223507 draws its Latvian parent; the workflow log prints how many companies are obliged with none filed.
