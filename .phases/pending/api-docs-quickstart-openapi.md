Items 4 and 5 of the Notion ticket "Improve OpenCheck API documentation" (Stephen, 25 Nov 2026). Quickstart: `frontend/src/lib/apiQuickstart.ts` holds three snippets (search, then lookup, then export as BODS JSON) and a stream example per language, rendered on /api with a language switch (`ui/Button`, `aria-pressed`) and a copy control; it replaces the one-line "Quick start" card. Each was run against production on 25 Nov 2026. The Python and JavaScript helpers wait out a 429 once for `Retry-After` seconds. The stream example reads `/stream` (the name search), which is open to scripts; the check streams refuse them with a 403, and the page says so. OpenAPI: `opencheck/openapi_docs.py` replaces `app.openapi` and rewrites FastAPI's schema for callers — the website's own pages (blog, entity pages, share cards, sitemaps, `llms.txt`) are left out; every public operation (62) has a tag (twelve, in order), a summary and a description in `OPERATIONS`, plus its rate tier read from the limiter (`x-rate-limit-tier` and a sentence); undescribed parameters get one from `PARAMETERS`; phase notes are stripped from every description; streams declare `text/event-stream` and downloads their file types; errors share an `Error` schema (`{"detail"}`) with 400/403/404/409/429 (with `Retry-After`)/502/503 where they apply. `opencheck/openapi_examples.json` holds recorded examples for `/lookup` (cut from the /api sample, restricted sources removed), `/search` (restricted sources' results removed, `raw` emptied), `/resolve-national-id`, `/knowability`, `/health` and `/sources`, built by `backend/scripts/build_openapi_examples.py`. `backend/tests/test_openapi_docs.py` fails when a public route is not in `OPERATIONS`, an entry names no route, "Phase N" reaches the schema, a parameter is undescribed, a limited route lacks its tier or 429, a stream or download claims JSON, or an example does not validate against its response model; `test_api_reference.py` pins the quickstart's routes and fields. `SourceHit.is_stub`'s description no longer names Phase 0 (data dictionary regenerated). Rebuild the examples when a response shape changes.
