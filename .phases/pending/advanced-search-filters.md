From the OO usable-data check (feature 3, "Search by other details" — the one OO feature OpenCheck did not meet). Stephen's decisions (3 Nov 2026): approach A — one quiet "More filters" control under the Company name box, fields in the page flow, set filters always visible as removable chips (`MoreFilters`, `ui/FilterChip`); the legal form waits for a jurisdiction and lists that jurisdiction's ISO 20275 forms, most used first by issued LEIs in the Golden Copy mirror, abbreviation in bold (`LegalFormPicker`, an APG combobox; `GET /elf-forms`); a source that cannot apply an active filter is left out and named (`filters.applied_by` / `left_out` on `/search`, a `filters` event on `/stream`, the same block and a hint on `opencheck_search`), never run unfiltered; nationality and birth year for people in the API and MCP only (OpenSanctions and Wikidata, applied to their own data; Wikidata fails closed).

Checking the claims against GLEIF found two things the ticket had wrong: the parameter is `filter[entity.legalForm]` (`.id` is HTTP 400), and GLEIF's jurisdiction filter matches each part of a code, so `DE` also returns 145,738 Delaware records, `PA` 9,291 Pennsylvania, `KY` 1,490 Kentucky and `SH` 162 Sharjah against 3 Saint Helena. For the 31 clashing codes (`data/gleif_jurisdictions.json`, generated by `scripts/build_search_filter_data.py` from GLEIF's accepted jurisdictions; the website's copy is pinned equal) the search scans 200 records a page, up to five pages, keeps exact rows and corrects the total by subtracting each clashing sub-division's count — Stephen chose this over an approximate legal-address guard. Abbreviations come from GLEIF's downloadable ELF list only (`data/elf_forms.json`, v1.6), not its API.

The count line now says how many matched ("First 10 of 48,503 GLEIF records", where v1 said "10 results"), an empty filtered search is a neutral panel with chips to widen it instead of a red alert, and the LEI status pill reads "LEI issued" in the neutral tone. Docs: `docs/search-filters.md`. After deploy: check `/elf-forms?jurisdiction=DE` reports `counts_available: true` (the mirror) and that a Panama search shows no Pennsylvania rows.
