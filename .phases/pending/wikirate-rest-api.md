Stage 2 of the Wikirate platform move. Wikirate 2.0's REST API (`data.wikirate.org/rest/v1`, documented at wikirate.org/api) launched on 1 Nov 2026; the legacy API, read since the previous phase at legacy.wikirate.org, is retired after 31 Dec 2026. With `WIKIRATE_PUBLISHABLE_KEY` and `WIKIRATE_API_TOKEN` set the adapter reads the REST API: the company by LEI from `v1_companies` (Wikidata fallback), the data-point total from `v1_answers` with `Prefer: count=exact`, and the twelve latest researched answers. Every request sends `apikey`, `x-api-token` and `Accept-Profile: api`. `WIKIRATE_BACKEND` (`auto`, the default, reads REST when its credentials are set and the legacy API otherwise; `rest`; `legacy`) makes a rollback a Render setting, not a deploy. Measured on 2 Nov 2026 against the documentation, which is wrong in two places: `company_identifiers` keeps the legacy key names (`legal_entity_identifier`, `wikidata`, `international_security_identification_number`, …), not the documented `lei` / `isin`, so a lookup on `lei` finds nothing; and a counted answer is HTTP 206. 22,037 companies carry an LEI, none as a list. The two renamed keys are mapped onto the bundle's names, so the BODS mapper and hit builder are unchanged. Company ids are the legacy card ids; totals were BP 2,295 (legacy 2,290), Eli Lilly 2,223 (2,223) and Rosneft 1,369 (1,317). Every answer carries its own licence, all CC BY 4.0 for the three; a sample answer under another licence is left out and counted (`answers_other_licence`). A failed request, a non-list body, a count without a total and a 401 for a revoked token record degradations, as on the legacy path, and nothing that failed is cached (namespace `wikirate-rest`). Answers have no public page and the new site's data explorer needs a login, so a REST card links the company page once with its data-point count (`lib/wikirateLinks.ts` `wikirateCardLinks`); legacy runs and saved reports keep their links. The weekly source-health sweep reads the REST API once the GitHub secrets `WIKIRATE_PUBLISHABLE_KEY` and `WIKIRATE_API_TOKEN` exist. Tests run on real responses for BP. Post-deploy: Eli Lilly, Rosneft and BP with `refresh=true` return `api: "rest"` hits with the totals above; set `WIKIRATE_BACKEND=legacy` on Render to compare. Before 31 Dec 2026: remove the legacy path, `WIKIRATE_API_KEY` and its secret, and point the probe's `requires_env` at the REST values.
