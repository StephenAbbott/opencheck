---
title: OpenAleph is read from its new home, darc.zone.
readme: OpenCheck now calls OpenAleph's flagship at darc.zone, after the old search.openaleph.org address started redirecting there.
---
OpenAleph's flagship instance moved from search.openaleph.org to darc.zone (DARC.ZONE, Data and Research Center; version 5.4.0) by 16 Nov 2026, and the old host now answers every path with a 301. The live API smoke run failed on it (its client does not follow redirects), and production was quietly worse off: `build_client()` follows redirects, but httpx turns a redirected POST into a GET and drops the Authorization header across origins, so the FtM `/match` step and both related-party percolation calls failed on every lookup (Eli Lilly on 17 Nov 2026: "The percolation person call failed; 43 of 53 related-party name(s) were not screened") and keyed GETs ran anonymously. `_API_BASE` and the FtM mapper's record link now name darc.zone, with a comment saying why a redirect is not enough. Check in production: a lookup's `degraded_sources` carries no `openaleph_percolation` entry, and OpenAleph links open on darc.zone. DARC.ZONE's banner says it changed user groups and access levels; if datasets the key used to read have gone, that is an access question for hi@dataresearchcenter.org, not a code one.
