title: Wikirate is read from its legacy host, and a Wikirate failure is no longer read as "no record".
readme: Wikirate data is back on the Climate & ESG tab, read from legacy.wikirate.org after Wikirate 2.0 took over wikirate.org, and a failed Wikirate read now says so instead of reading as no record.
tests: backend +8, vitest +6, vitest_files +1
---
On 1 Nov 2026 Wikirate 2.0 took over wikirate.org and the legacy platform and its API moved to legacy.wikirate.org, where Wikirate keeps them until 31 Dec 2026 (its email to API users). The new wikirate.org answers every legacy API path with HTTP 200 and its website's HTML; the adapter caught the failed JSON parse and returned "no record", so from 1 Nov the Climate & ESG tab said Wikirate had nothing on BP, Eli Lilly and Rosneft, with the source marked live and no degradation (production, 2 Nov 2026). The adapter now calls legacy.wikirate.org with the same X-API-Key (BP answers 2,290 data points there), under a new cache namespace. `_get_json` refuses a body that is not JSON and `/Companies.json` without an `items` list (`WikirateUnexpectedResponse`); a failed company resolution or card read records a `source_fetch` degradation, which the pipeline reports as "Did not answer" with Try again, and a failed answers read records `source_read`, so the card no longer shows a silent "0 data points". A 404 card and an empty company list remain answers. The Climate & ESG card links the data points to legacy.wikirate.org and the company page to wikirate.org/company/{id} (`lib/wikirateLinks.ts`); a platform.wikirate.org link frozen in a saved report or the replay cache from 10 Oct–1 Nov is moved onto wikirate.org. JSON fixtures were re-captured from the legacy host and the new site's answer kept as `new_platform_card_path.html`. Post-deploy: `/lookup-source?source_id=wikirate&refresh=true` for Eli Lilly (`FRDRIPF3EKNDJ2CQJL29`), Rosneft (`253400JT3MQWNDKMJE44`) and BP (`213800LH1BZH3DI6G760`) returns a hit with data points, and the card's two links open. Stage 2 — a new wikirate.org account and token, and the adapter moved onto Wikirate's new REST API — must ship before the legacy API is retired after 31 Dec 2026.
