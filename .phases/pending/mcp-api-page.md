A follow-up to the "Update MCP approaches" ticket (25 Nov 2026). Phases 617–619 moved the MCP server to SDK v2 and protocol revision 2026-07-28 and added skills and tasks, and the only docs they changed were `docs/mcp-server.md` and `/.well-known/mcp.json`, so the /api#mcp page said nothing about any of the three. A "What newer clients get" card now sits between Connect and the call order. It names both revisions, lists the three skills (`opencheck-due-diligence`, `reading-opencheck-results`, `opencheck-ownership-questions`) with a line each, and explains tasks: a call to a tool that spends the lookup budget becomes a task after three seconds, the client polls every five, and polling spends no budget. The Connect step notes that the guide names the skills. The values are in `lib/mcpTools.ts` (`MCP_PROTOCOL_VERSIONS`, `MCP_SKILLS`, `MCP_TASK_FAST_PATH_S`, `MCP_TASK_POLL_S`), and `test_api_page_mcp.py` pins them to the descriptor, to `load_skills()` and to `mcp/tasks.py`. A third test pins that the tools able to become tasks are exactly the budget tools, which is what the page claims.
