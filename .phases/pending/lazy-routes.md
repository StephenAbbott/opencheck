The "Speed up first load of the opencheck.world homepage" ticket (31 Oct 2026). A first-time visitor saw a blank page for 1.8 s on a good connection and 3.3 s on slow 4G: the HTML is an empty shell and nothing drew until a 1,434 KB entry chunk (495 KB brotli) had downloaded and run. 882 KB of it was `lib/statusMarkdown.json`, the changelog's data, in the entry only because `App.tsx` imported `ChangelogPage` statically, along with `SourcesPage`, `FeaturesPage`, `BehindTheScenesPage`, `ApiPage`, `BatchPage`, `WatchlistPage` and `EsgPanel`. All eight are now lazy chunks, each page inside a `LazyPage` (a `PanelBoundary kind="part"` + `Suspense` with `PanelLoading`) and the ESG tab inside its own `PanelBoundary`, the Phase 331 shape. The entry is now 370 KB (97 KB brotli); on a local production build with slow 4G simulated, first contentful paint went from 3.4 s (production) to 1.1 s. A latent trap in `lazyWithRetry` was found on the way: its retry imports the chunk's URL directly, so a `.then((m) => ({ default: m.Page }))` chained onto the factory ran on the first attempt only and the retried page rendered `undefined` (React error 306). Every existing call site used a default export, so production was not affected; `lazyNamedWithRetry` / `importNamedWithRetry` pick a named export after the retry, and `lazyWithRetry`'s docstring now says a factory must be a bare `import()` of a default export. `e2e/chunk-failure.spec.ts` gains two cases for a page chunk (one 502 then the retried page renders; a permanent 404 breaks only that page and the header still navigates). `frontend/scripts/measure-cold-load.mjs` measures a cold load (cache disabled, unthrottled and slow 4G, median of N runs) so every step on the ticket is measured the same way. Render Edge Caching ("Common static files") was switched on the same day in the dashboard: `/assets/*` answers `HIT` from the second request, while `/`, `/version.json` and `/export` stay uncached. After deploy, run the script against https://opencheck.world/ and paste the table on the ticket.
