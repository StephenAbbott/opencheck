---
title: The changelog's summary paragraph wraps long tokens, as its title already did.
readme: The changelog page no longer scrolls sideways on a phone when a status row carries a long filename or identifier.
---
Found by the release steward on 16 Oct 2026: after the Phase 356 row landed on `main`, the e2e smoke test `changelog reflows without a sideways scroll` (320px) failed on every pull request (`scrollWidth` 364 against a 320px viewport), while `main` itself showed no red run because the stamp commits are `[skip ci]`. The row's body carries the 51-character token `ettevotja_rekvisiidid__kandevalised_isikud.json.zip`; `changelog.ts` strips the backticks, so it reaches the page as one unbreakable word, and `ChangelogPage.tsx` gave the entry title `[overflow-wrap:anywhere]` but never the summary paragraph beneath it. The summary `<p>` now carries the same class — `overflow-wrap: anywhere` rather than `break-word`, so the break opportunity also counts in min-content sizing. One class, no words changed, no test added: `e2e/smoke.spec.ts:242` is the test that caught it and is the check that it is fixed. Check in production that `/changelog` at 320px shows the Phase 356 entry with the filename broken across lines and no horizontal scroll.
