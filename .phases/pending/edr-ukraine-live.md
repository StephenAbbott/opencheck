Phase 206 built `edr_ukraine` (adapter, parsers, two-pass index builder, mapper, 44 tests) and deliberately left three gates: the code on `main`, an index that existed only on one laptop, and the wiring into the lookup — because a 967 MB index "could not live on Render". That premise expired with Phase 180's persistent disk (10 GB at `/var/data`, holding the 1.8 GB GLEIF mirror), so this phase clears the other two gates in the `jar_lithuania` shape. The adapter is in `REGISTRY` with `LookupDeriver(UA_RA_CODES, "ua_edrpou", normalise_edrpou)` — all three authorities that register Ukrainian LEIs (RA000567 ЄДР, RA001026 NSSMC, RA001027 NBU) file the 8-digit EDRPOU — a `_bh_edr_ukraine` hit builder, a `finding_edr_ukraine` sentence (status, legal form, beneficial owners or the class of the filed absence, founders, signatories, a state authority), a probe (ТОВ «КИЇВ-АРТ», `requires_files`, snapshot, 28 days), the boot warm-up and the sweep warm-up. Dispatch is gated on the index (`covers_lei`), a code the index does not hold is a note card saying what the index holds (the ownership graph: live entities with a BO record, a corporate founder or a state authority, plus every founder target — about 800,000 of 2.0M), and a read failure is a `source_read` degradation. The module-level shared read-only connection checks `meta.schema_version` (1); `declare_snapshot` dates statements by the export's cut and the build's time. The index is built off-datacentre by `scripts/refresh_edr_ukraine_index.sh` (download, build with `--gzip`, upload through `replace_release_asset.sh`) because data.gov.ua answers HTTP 403 to every datacentre address — the cloud and a GitHub runner — and 206 to a home connection; `EDR_UKRAINE_DB_URL` names the `edr-ukraine-index` asset and `warm_index` downloads it when absent or changed. Two mapper corrections: a founder row naming a class of people rather than a person ("ФІЗИЧНІ ОСОБИ", "НЕВІДОМІ ОСОБИ", "ПРИВАТНІ ОСОБИ В КІЛЬКОСТІ 112 ОСІБ" — 10,110 rows) is an unspecified party with `informationUnknownToPublisher` and the register's words, never a person node (the Phase 199 GEM placeholder rule), so no phantom person reaches the graph or the related-party screens. Stephen confirmed the `bo_regimes` entry (`review_status` verified, 29 Oct 2026). The National ID picker gains Ukraine with the two other authorities as `sameNumberAuthorities`, and `GleifAdapter.search_by_local_id` widens a Ukrainian scope to all three, the French arrangement. `UA-EDR` becomes a FullCheck register hop by construction. Counts 52 → 53 (homepage, README, social card); OKF, lineage and knowability regenerated — the Ukraine knowability sentence now says OpenCheck reads beneficial owners from the ЄДР. After deploy: upload the index (the refresh script, from a home connection), watch the boot log for "EDR Ukraine index warm-up: downloaded", then look up `254900UI956MSQXOL287` (КИЇВ-АРТ) and expect a ЄДР card with one beneficial owner at 100 %; `/sources` reports 53.
