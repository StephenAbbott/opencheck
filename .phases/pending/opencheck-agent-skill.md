For the Connected Data London 2026 masterclass (Notion ticket "OpenCheck agent skill with evals, for Connected Data London 2026 attendees", modelled on NVIDIA Auto Ontology's skills). `skills/opencheck-due-diligence/` holds `SKILL.md` (the call order from cheap to budgeted, the bulk datasets for anything over 20 companies, and the reading rules: degraded is not clean, context is not risk, a name match is not an identity, GLEIF consolidation is not ownership, the LEI's status is not the company's, 13F managers are not owners, integrated figures per source and never added, several bodies of one state are one holding, licences travel with the data), two references (`bods-shapes.md` — recordId references, interests, closed records, OpenCheck's extension keys; `bulk-datasets.md` — the Laundromat, Estonia and MEIP releases and how to load them) and `evals/`. Stephen's decisions: a `skills/` directory, one skill, Claude only, no CI check. The twelve cases in `evals/evals.json` each rest on a production MCP response recorded verbatim on 5 Nov 2026 (`evals/files/`: Shell, Bentcard Import LLP, Metastar Invest LLP, a four-company batch with Heineken's KvK not answering, Equinor and Persia International Bank owners, Eli Lilly, Ørsted, Cyprus knowability, Shell's subsidiaries, a Persia BODS export), so runs read files and spend no lookup budget. Benchmark (`evals/BENCHMARK.md`, answers and blind gradings under `evals/results/2026-11-05/`): clean `claude -p` sessions with no CLAUDE.md and the server's handshake as the system addendum, skill installed rather than injected, each pair graded blind. Opus 5.5 98% vs 92% of assertions, 1 vs 5 wrong claims; Haiku 5.5 96% vs 91%, 5 vs 8. The clearest gain is bulk exploration (Haiku without the skill wrote a 40-minute live loop of 200 lookups). Most cases pass without the skill because OpenCheck's responses already explain themselves — the baseline starts above 90%, unlike NVIDIA's 47.7%. A first run made with sub-agents that had the repo's CLAUDE.md in context was discarded as contaminated. After the run the description was widened (Haiku skipped the skill on 4 of 12 prompts that named OpenCheck output but not "owners"; 4 of 4 after) and two rules added (one state's bodies are one holding; no percentage column from GLEIF), each re-checked on both models. `evals/runner/` re-runs it from any machine with Claude Code. Found while recording: `opencheck_search` candidates carry `jurisdiction: null` although the handshake tells agents to pass it to `opencheck_knowability`, and Bentcard's LEI files a Baku address so its lookup never reaches the dissolved Companies House record OC369315.
