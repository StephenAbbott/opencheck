Follow-up to Phase 403 (Notion "Stamp declarationSubject in the bulk build scripts"), whose after-merge step was to re-issue the Estonia dataset from `main`. The re-issue is the `dataset-estonia-2026-10-25` release, and the expected numbers in the comments of `backend/scripts/estonia_demo_queries.cypher` — the file shipped byte-identical as `demo_queries.cypher` in the release's Neo4j zip — now match it: measured by loading `estonia-2026-10-25.jsonl.gz` with bods-neo4j 1775533 into Neo4j 5.26 + APOC 5.26 on 26 October 2026 and running every query. Comments only; no query changed and no code changed, so no test is affected. Against the 19 October figures: Person nodes 88,165 → 88,349 and Entity nodes 73,931 → 74,069; OWNS edges 81,760 → 81,910; the join on the registry code 28,664 of 29,183 → 28,729 of 29,246; LEI companies with a named beneficial owner 25,312 → 25,370; natural-person reporting exceptions with a named owner 15,438 / 13,610 → 15,497 / 13,662; former founders 8,554 → 8,569. Nothing to check in production — the file is read by anyone loading the release into Neo4j.
