title: The AI summary's output is bounded whatever the packet's size.
readme: The AI summary now caps its own length and claim count, so heavily sanctioned groups such as Rosneft no longer fail at the model's token ceiling.

Rosneft's `/narrative` answered 502 on 14 Oct 2026: the `emit_summary` call stopped at `max_tokens` (4000) and the guard in `summarise.py` refused the claimless result. The failure was intermittent. Measured on 15 Oct under prompt v9, Rosneft's packet (86 risks, 131 facts, ~38k input tokens) produced 2,663–3,292 output tokens over six runs: a ~2,250-character paragraph restated across 16–25 claims, growing with the number of risks. Input size was not the constraint. Two levers (Stephen's choice, Notion "AI summary fails on large packets (Rosneft max_tokens truncation)": options 1 and 3; grouping risks in the packet and a reduced-packet retry were not done). `MAX_TOKENS` is 8000, as headroom. Prompt v10 (`2026-10-15-v10`) caps the output in the prompt and the tool schema: `SUMMARY_MAX_WORDS` 180 (stated in words because a characters-only cap of 1,200 was overrun on every run), `SUMMARY_MAX_CHARS` 1,500 (`maxLength`), `MAX_CLAIMS` 12 (`maxItems`), `MAX_LIMITATIONS` 6. Many items of one kind are summarised by kind with a count and at most three examples, and a claim about a group cites every id it covers. The API treats schema limits as guidance, so `validate_narrative` records an overshoot in `validation_issues` and never drops a grounded claim. Measured on the same Rosneft packet under v10: 1,736–1,974 output tokens over eight runs, 1,398–1,513-character summaries, 12 claims, ~30 s instead of 45–55 s; Eli Lilly ~1,710 tokens, 1,114 characters, 11 claims. One v10 run sent `claims` as a single JSON string; `_raw_tool_output` now decodes `claims` / `limitations` sent as JSON text and refuses text that is not a list (the validator would have failed on the first character). `NarrativeResult.output_tokens` carries the model's usage; `eval_narrative.py` prints it beside each packet and gains a `within_caps` column; `tests/golden_narrative/07_many_related_party_risks.json` is a synthetic packet of Rosneft's shape (88 risks, invented names). Found alongside: `EU_HIGH_RISK_THIRD_COUNTRY` and `EU_TAX_NON_COOPERATIVE` are emitted once per source (five each for Rosneft) — ticketed separately. Check in production: `GET /narrative?lei=253400JT3MQWNDKMJE44` answers 200 with `prompt_version` `2026-10-15-v10` and at most 12 claims, and the curated Rosneft card's summary generates.
